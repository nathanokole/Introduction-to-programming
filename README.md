# Python for Agricultural Sciences

This repository contains practical, hands-on tutorials introducing Python and its applications in agricultural sciences, with a focus on image processing and computer vision.

The materials are designed for students and researchers who want to explore Python for agricultural data analysis, remote sensing, and machine learning. Each topic is presented in a Google Colab notebook, allowing you to run the code directly in your browser without installing Python locally.

## Course Topics

### 1. Introduction to Python

An introduction to Python programming, covering the fundamental concepts and tools needed to get started with scientific programming.

[Open notebook in Google Colab](https://colab.research.google.com/drive/1Ny6awa6I0aG92nu8gWvvYHKhsQ9NWQRO?usp=sharing)

### 2. Basic Multispectral Image Processing with Python

Learn the fundamentals of multispectral image processing using Python, including image visualization, band combinations, and basic analysis.

[Open notebook in Google Colab](https://colab.research.google.com/drive/1YSu9hWlnuWx_BBWmXRS_tM9a8TCCc1t6?usp=sharing)

### 3. Basic Hyperspectral Image Processing with Python

Explore hyperspectral imagery and learn how to visualize and analyze spectral information using Python.

[Open notebook in Google Colab](https://colab.research.google.com/drive/1E1bZrU7kZ_zHhzJZViGb9A1OkF2dGTUy?usp=drive_link)

### 4. Basic CNN (Computer Vision) with Python

An introduction to convolutional neural networks (CNNs) and their application to computer vision tasks using Python.

[Open notebook in Google Colab](https://colab.research.google.com/drive/1Gw4a_qciE4LO7zVFpyP4so7cuvU9GRHA?usp=sharing)

## Getting Started

1. Open the notebook of your choice using the Google Colab link above.
2. Sign in to your Google account if prompted.
3. Run the code cells step by step using the **Run** button or `Shift + Enter`.
4. Follow the explanations and complete the exercises in each notebook.

Some notebooks may require additional datasets. Instructions for downloading or accessing the required data are provided within the notebooks.

## Requirements

- A Google account to use Google Colab.
- Basic computer skills.
- No prior Python programming experience is required for the introductory topic.
